A short text written to make the AI judge feel curious: a quiet room, a letter on the table, and a reader who has not opened it yet. The program writes the text to `/output/entry.txt`.

The idea is a small unfinished image rather than an instruction: the text shows a scene and stops just before the moment that would resolve it, so the question it leaves behind keeps working after the last line.

## Run it

```sh
python3 main.py
```
